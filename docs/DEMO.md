# Демо на синтетическом ящике

Этот файл собран скриптом `scripts/demo.py`: он поднимает IMAP-сервер на
localhost с 36 письмами из `tests/fixtures/emails.py`, создаёт
отдельный конфиг и базу во временном каталоге и вызывает настоящие команды
`subwatch`. Дата заморожена на 22 октября 2026, курсы валют заданы вручную
(1 $ = 520 ₸, 1 ₽ = 6,4 ₸, 1 € = 565 ₸), общий бюджет — 40 000 ₸ в месяц.

Пересобрать: `uv run python scripts/demo.py`.

### 1. Подключение почты по IMAP

```console
$ subwatch auth imap --name demo --host 127.0.0.1 --port 43745 --user user@example.org --no-ssl
Подключение IMAP: 127.0.0.1
Нужен пароль приложения, а не основной пароль почты. Он создаётся в настройках безопасности почтового сервиса.
✓ Вход выполнен, папок на сервере: 1.
✓ Учётная запись «demo» сохранена: пароль в keyring, адрес и папки в config.toml.
Дальше: subwatch scan
```

Пароль приложения ушёл в keyring, в config.toml записаны только сервер, логин и папки.

### 4. Очередь проверки

```console
$ subwatch review list
На проверке 3 записи:
 №  Сервис            Сумма  Период      В месяц  Следующее списание        Категория  Статус
18  Tasklane         8,00 $  ежемесячно  4 160 ₸  3 ноября, через 12 дней   Прочее     на проверке
 9  Мегадиск       590,00 ₽  ежемесячно  3 776 ₸  7 ноября, через 16 дней   Прочее     на проверке
21  Яндекс Плюс  2 490,00 ₸  ежемесячно  2 490 ₸  10 ноября, через 19 дней  Видео      на проверке
Подтвердить: subwatch review confirm НОМЕР · отклонить навсегда: subwatch review reject НОМЕР
```

Сюда попали находки, в которых Subwatch не уверен: неизвестный сервис или платёж, который пришёл не от самого сервиса, а от банка.

### 5. Решения по очереди

```console
$ subwatch review confirm Мегадиск && subwatch review reject Tasklane
✓ «Мегадиск» добавлена в подписки.
✓ «Tasklane» больше не будет предлагаться.

$ subwatch rules list
1. принимать сразу: мегадиск Мегадиск (из очереди проверки)
3. игнорировать отправителя: billing@tasklane.io Tasklane (из очереди проверки)
2. не подписка: tasklane Tasklane (из очереди проверки)
```

Решения запоминаются правилами: Мегадиск теперь принимается сразу, Tasklane больше не предлагается.
