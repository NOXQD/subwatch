# AI-слой

По умолчанию выключен, и для большинства писем не нужен: известные сервисы
и типовые чеки разбираются правилами. Модель помогает с остальным —
письмами незнакомых сервисов или с необычной вёрсткой.

## Когда модель вызывается

Только для писем, которые правила не смогли уверенно разобрать: есть
признаки подписки, но не хватает суммы, периода или уверенности. Не
отправляются никогда:

- письма с кодами подтверждения, сбросом пароля, уведомлениями о входе;
- заказы и доставки без известного сервиса — на них не стоит тратить
  запросы.

Ответ модели сам по себе не добавляет подписку в список: находка от
модели получает не больше 0.75 уверенности и идёт в очередь проверки.
Если модель подтверждает то, что нашли правила, уверенность растёт.

## Что отправляется

Перед отправкой текст проходит очистку:

- удаляются адреса почты, номера карт (полные и маскированные), телефоны,
  IBAN, длинные номера, коды после слов «код»/«code»;
- ссылки сокращаются до домена — токены в адресах не уходят;
- выбрасываются строки с приветствием («Здравствуйте, Иван!») и почтовым
  адресом;
- из остального остаются только строки с цифрами или словами про оплату и
  подписку, и не больше `ai.max_input_chars` символов;
- вместо адреса отправителя — только его домен.

Посмотреть точный текст, ничего не отправляя:

```bash
subwatch scan --ai-dry-run            # для новых писем
subwatch scan --ai-dry-run --full --reprocess   # для всего ящика
subwatch ai test письмо.eml --dry-run # для одного письма
```

Пример — в [DEMO.md](DEMO.md), раздел 13.

Для облачных провайдеров очистка делается всегда. Для локальной модели
её можно отключить (`ai.redact_local = false`) — текст всё равно не
покидает компьютер.

## Настройка

Локально через [Ollama](https://ollama.com):

```bash
omarchy pkg add ollama && systemctl enable --now ollama
ollama pull llama3.1:8b
subwatch config set ai.enabled true
```

```toml
[ai]
enabled = true
provider = "ollama"
model = "llama3.1:8b"
api_base = ""                 # http://localhost:11434 по умолчанию
```

Облако со своим ключом (ключ хранится в keyring):

```bash
subwatch config set ai.provider openai
subwatch config set ai.model gpt-4o-mini
subwatch auth ai
```

Без дополнительных пакетов работают Ollama, Anthropic и любой
OpenAI-совместимый API: `openai`, `openrouter`, `groq`, `deepseek`,
`mistral`, `together`, `lmstudio`, `vllm`, или `openai_compatible` со
своим `api_base`. Остальных провайдеров поддерживает LiteLLM — он ставится
отдельно (`./install.sh --with-ai`), потому что тянет за собой около 60
пакетов.

## Лимиты и журнал

```toml
max_requests_per_scan = 20
max_requests_per_day = 100
timeout = 60
audit_payloads = false
```

Каждый реальный запрос записывается в базу: время, провайдер, модель,
локальная или облачная, домен отправителя, размер и хэш текста. Сам текст
сохраняется, только если включить `audit_payloads`. Смотреть —
`subwatch privacy`.

Если модель недоступна или ключа нет, сканирование продолжается без неё,
причина пишется в журнал.
