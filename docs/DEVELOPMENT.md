# Разработка

```bash
uv sync
uv run pytest            # около 400 тестов, ~40 секунд, без сети и без ключей
uv run ruff check src tests
uv run subwatch --help   # запуск из исходников
uv run python scripts/demo.py   # пересобрать docs/DEMO.md
```

Тесты работают в отдельном XDG-дереве во временном каталоге, с keyring в
памяти, замороженной датой (22 октября 2026) и без доступа к настоящему
Hyprland, systemd и демону уведомлений. IMAP проверяется на маленьком
сервере из `tests/mock_imap.py`, Gmail — на поддельном объекте API, модели
— на подставленной функции.

## Устройство

```
src/subwatch/
  __main__.py          вход: быстрый путь для `bar`, выбор языка, CLI
  config/              схема (pydantic), загрузка с приоритетами, правка через tomlkit
  i18n.py, fmt.py      каталог строк, плюралы, форматирование дат и денег
  sources/             источники: gmail, imap, statements, manual + реестр плагинов
  extract/             разбор писем: справочник, ключевые слова, регулярки, очистка
  ingest.py            находка → подписка, списание, события
  recurrence.py        повторяющиеся списания в выписках
  scan.py              сканирование целиком и реакции (хуки, уведомления)
  reminders.py         расписание и рассылка напоминаний, действия
  analysis.py          итоги, бюджеты, дубли, «зомби», траты по месяцам
  fx.py                курсы валют
  ai.py                необязательный AI-слой
  db.py, crypto.py     SQLite и шифрование
  integrate/           systemd, панель и меню Omarchy, Hyprland, Waybar, ярлыки
  cli/                 команды (typer) и перевод интерфейса typer/click
  tui/                 Textual
  gui/                 данные для виджета и окна, описание настроек, gui-server
  ops.py, userinput.py правки подписок и разбор ввода, общие для CLI, TUI и окна
  resources/           справочник сервисов, ключевые слова, валюты, шаблоны банков,
                       стандартный config.toml, каталоги строк
  resources/omarchy/plugin/   QML-плагин для omarchy-shell: виджет, карточка, окно
```

Путь письма: источник отдаёт `RawMessage` → `extract.engine.analyse`
решает, похоже ли это на подписку, достаёт сумму, период и даты и считает
уверенность → при необходимости `ai.py` уточняет → `classify` назначает
категорию и теги → `Ingestor` создаёт или обновляет подписку и
возвращает события → `scan.react` запускает хуки и уведомления.

## Правила для кода

- Весь видимый пользователю текст — только через каталог: `t("ключ")`,
  `tn("ключ", n)`. В исходниках Python нет кириллицы, а английские строки
  не передаются в вывод напрямую — это проверяет `tests/test_i18n.py`.
  Там же проверяется, что ключи есть в обоих каталогах, что плейсхолдеры
  совпадают с местами вызова и что в каталоге нет мёртвых строк.
- Языковые данные для разбора писем (слова, месяцы, регулярки для
  очистки) — в `resources/keywords.toml`, не в коде.
- Новая настройка: поле в `config/schema.py`, строка с комментарием в
  `resources/config.default.toml` (тест сверит одно с другим) и тест,
  который показывает, что настройка меняет поведение.
- Ошибки для пользователя — `SubwatchError("ключ", hint="ключ подсказки")`.
- Деньги — `Decimal`, даты — через `clock.today()` / `clock.now()`.

## Виджет и окно

QML лежит в `src/subwatch/resources/omarchy/plugin/` и ставится командой
`subwatch integrate apply --only bar`; путь к `subwatch` и каталог кэша
плагин получает из `Env.js`, который пишется при установке. Тексты — из
таблицы `[gui.ui]` каталога строк, их присылает Python
(`subwatch bar --format panel` для карточки, команда `hello` gui-server для
окна).

`tests/test_gui.py` проверяет бэкенд окна, описание настроек (у каждого
параметра есть подпись на обоих языках), установку плагина и компилирует
все QML-файлы в Quickshell без экрана (`QT_QPA_PLATFORM=offscreen`), если
Quickshell и оболочка Omarchy есть в системе. После правки QML на живой
системе нужен `omarchy restart shell`: оболочка не перечитывает уже
скомпилированные файлы.
