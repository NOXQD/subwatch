# Subwatch

Трекер подписок для [Omarchy](https://omarchy.org). Сам находит подписки в
почте и банковских выписках, показывает, сколько они стоят в месяц, и
заранее напоминает о списаниях. Работает локально: никаких серверов, база
лежит у вас в `~/.local/share/subwatch`, токены — в системном keyring.

```
$ subwatch upcoming --days 14
Списания в ближайшие 14 дней:
Дата        Когда          Сервис             Сумма
25 октября  через 3 дня    Notion           10,00 $
25 октября  через 3 дня    Казахтелеком  6 500,00 ₸
1 ноября    через 10 дней  Beeline       3 290,00 ₸
2 ноября    через 11 дней  ChatGPT Plus     20,00 $
```

Полный прогон на тестовом почтовом ящике — в [docs/DEMO.md](docs/DEMO.md).

## Что умеет

- Читает Gmail (OAuth, только `gmail.readonly`) и любую почту по IMAP с
  паролем приложения. Ящики открываются только на чтение, письма не
  помечаются прочитанными. Повторное сканирование читает только новое.
- Понимает письма на русском, английском и казахском: чеки, продления,
  пробные периоды, смену цены, отмены. Справочник знает около сотни сервисов
  — от Netflix и Яндекс Плюс до Kcell и Kaspi-платежей, его можно дополнять.
- Импортирует выписки CSV и PDF (есть шаблоны для Kaspi Gold и Т-Банка,
  остальное — ручной разметкой колонок) и находит в них повторяющиеся
  списания.
- Сомнительные находки складывает в очередь проверки. Ваше «да» или «нет»
  запоминается правилом.
- Напоминает через уведомления Omarchy (или mako/dunst) по правилам: за
  сколько дней, во сколько, для каких сервисов, категорий и сумм; с тихими
  часами, повтором и действиями «оставить / отменить / отложить».
- Считает траты в базовой валюте с курсами Нацбанка РК, ЦБ РФ или ЕЦБ,
  следит за бюджетами, подорожаниями, дублями и подписками, которыми давно
  не пользуетесь.
- Встраивается в Omarchy: модуль панели, пункт в меню, горячие клавиши,
  таймеры systemd. Есть TUI с графиками и календарь `.ics` для любого
  календаря.
- Необязательный AI-слой (Ollama или свой ключ) для писем, которые правила
  не разобрали. Перед отправкой из текста вырезаются личные данные, а
  `--dry-run` показывает, что именно уйдёт.

Интерфейс, справка, уведомления и сообщения об ошибках — на русском. Язык
переключается в настройках (`ui.language = "en"`), можно добавить свой
перевод файлом, без правки кода.

## Установка

Нужны Omarchy (или другой Arch с Hyprland) и доступ в интернет для
установки зависимостей.

```bash
git clone <адрес репозитория> subwatch
cd subwatch
./install.sh
```

Скрипт ставит [uv](https://docs.astral.sh/uv/) (если его нет), сам
Subwatch в изолированное окружение (`uv tool install`), создаёт
`~/.config/subwatch/config.toml` с комментариями к каждому параметру,
включает таймеры и подключает панель, меню, клавиши и автодополнение.
В конце запускается `subwatch doctor`. Повторный запуск ничего не ломает;
`./install.sh --dry-run` покажет, что будет сделано.

Варианты:

```bash
./install.sh --with-ai          # с LiteLLM, если нужен облачный провайдер, кроме OpenAI-совместимых
./install.sh --no-integration   # только программа, без таймеров, панели и меню
./uninstall.sh                  # убрать программу и интеграцию, данные оставить
./uninstall.sh --purge          # заодно стереть базу и токены
```

## Первый запуск

```bash
subwatch auth gmail     # мастер по шагам: свой проект в Google Cloud, вход, токен в keyring
# или любая почта по IMAP:
subwatch auth imap --name yandex --host imap.yandex.ru --user me@yandex.ru

subwatch scan           # первое сканирование: по умолчанию за 12 месяцев
subwatch                # TUI
```

Без почты можно начать с выписки или ручного ввода:

```bash
subwatch import ~/Загрузки/kaspi-gold.pdf
subwatch add Netflix --amount "3 990 ₸" --next "1 ноября"
```

Дальше всё работает само: таймер сканирует почту раз в день, второй таймер
каждые 15 минут проверяет, не пора ли напомнить.

## Где что найти в Omarchy

| Что | Где |
|---|---|
| Модуль панели | справа на панели: ближайшее списание или сумма в месяц; клик — TUI, правый клик — меню, средний — сканирование |
| Меню | `SUPER + SPACE` → Subwatch, или `SUPER + CTRL + SHIFT + U` |
| TUI | `SUPER + CTRL + U` |
| Ближайшие списания уведомлением | `SUPER + CTRL + ALT + U` |
| Приложение | Subwatch в списке приложений, с действиями |

Клавиши настраиваются в `[keybinds]`; перед применением Subwatch проверяет,
не заняты ли они. Подробности — в [docs/OMARCHY.md](docs/OMARCHY.md).

## Команды

```
subwatch                    TUI
subwatch list               все подписки (--json, --sort, --category, --all)
subwatch upcoming           ближайшие списания (--days, --notify)
subwatch spend              траты по категориям (--by month), бюджеты
subwatch add / edit / remove / cancel / pause / resume / used / merge
subwatch scan               сканирование (--source, --full, --dry-run, --ai-dry-run)
subwatch import файл        выписка (--bank, --map, --save-template)
subwatch review             очередь проверки
subwatch config get|set|edit|reset|diff|check|show
subwatch auth gmail|imap|ai|status|revoke
subwatch export csv|json|ics
subwatch rates / budget / rules / plugins / keybinds / integrate
subwatch doctor             проверка установки (--fix)
subwatch privacy / purge    что хранится / стереть всё
```

У каждой команды есть `--help` на русском.

## Настройка

Всё, что влияет на поведение, лежит в одном файле
`~/.config/subwatch/config.toml`: правила напоминаний, тихие часы,
категории и их бюджеты, валюта и источник курсов, расписание и глубина
сканирования, фильтры, хуки, AI. Файл проверяется по схеме, ошибки
объясняются по-русски с номером строки, изменения подхватываются на лету.

Значение можно задать и не трогая файл. Приоритет такой:

1. флаг командной строки: `subwatch --set reminders.time=09:00 remind`;
2. переменная окружения: `SUBWATCH_REMINDERS__TIME=09:00`;
3. `config.toml`;
4. значение по умолчанию.

`subwatch config get reminders.time --source` покажет, откуда взялось
текущее значение. Справочник по всем разделам — [docs/CONFIG.md](docs/CONFIG.md).

## Приватность

Хранятся только извлечённые поля: сервис, сумма, даты, откуда узнали.
Текст писем не сохраняется (если не включить `extraction.store_snippets`),
идентификаторы писем — только хэши. Секреты — только в keyring. Базу можно
зашифровать (`storage.encrypt = true`). `subwatch privacy` показывает, что
лежит на диске и что когда-либо уходило в облачную модель, `subwatch purge`
всё стирает. Подробно — [docs/PRIVACY.md](docs/PRIVACY.md).
